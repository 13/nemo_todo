# Backlog

Deliberate omissions from v1. Nothing here is a known defect.

## Photos in an export
**What.** Exporting from Settings writes lists, tasks and subtasks, not the
pictures on them.
**Cost of leaving it.** A restored task comes back without its photos; the
server's own backup still holds them.
**What closing it takes.** A zip rather than a JSON file, with the bytes
beside the rows, and an import that feeds them through the photo store.

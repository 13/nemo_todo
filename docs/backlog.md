# Backlog

Deliberate omissions from v1. Nothing here is a known defect.

## Repeat rules the picker does not offer
**What.** The grammar reads `every:3d`, `every:6m` and `monthly:2nd-tue`;
the picker offers only the common ones, so the rest can be stored but not
chosen.
**Cost of leaving it.** Anything unusual has to be set by another client.
**What closing it takes.** An interval field and a weekday-and-ordinal
picker, which is a lot of screen for a rare choice. Worth doing when
someone actually wants one.
